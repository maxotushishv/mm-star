# MM STAR — ფოტო გალერეა და გადახდის/მიწოდების წესები

## რა შეიცვალა

- ადმინპანელში პროდუქტის რედაქტირებისას შესაძლებელია ერთ პროდუქტზე მაქსიმუმ 12 ფოტოს ერთდროული ატვირთვა. თითოეული ფოტო აიტვირთება უკვე არსებული დაცული `admin/upload-image` API-ით. ფოტოების გადალაგება შესაძლებელია „მთავარად“ ღილაკით, წაშლა — ✕ ღილაკით. ცვლილებები ინახება მხოლოდ „შენახვა“-ზე დაჭერის შემდეგ.
- პროდუქტის დეტალურ გვერდზე ჩანს მთავარი ფოტო და სხვა ფოტოების მინიატურები, რომელთა დაჭერით იცვლება დიდი ფოტო. ძველი ერთფოტოიანი პროდუქტებიც მუშაობს.
- მომხმარებლის მიერ „ფილიალში გადახდის“ არჩევისას ავტომატურად ირთვება „ფილიალიდან გატანა“. თბილისის და რეგიონის მიწოდების ღილაკები ითიშება.
- სერვერზე `POST /api/orders` ასევე აბრუნებს `BRANCH_PAYMENT_PICKUP_ONLY` (HTTP 400), თუ ვინმე სცდის ფილიალში გადახდას თბილისის ან რეგიონის მიწოდებასთან ერთად; შეკვეთა/რეზერვაცია ამ შემთხვევაში არ იქმნება.
- დარჩა FINA-ის 5-წუთიანი სინქრონიზაციის წინასწარ დამატებული კოდი და ILHAMA (№9) საწყობის კონფიგურაცია. ორი საწყობი არ დაგვიმატებია.

## განთავსება

1. შეინახეთ არსებული GitHub/Vercel პროექტის სარეზერვო ასლი.
2. ატვირთეთ ZIP-ის ფაილები თქვენს GitHub რეპოზიტორიაში, არსებული ფაილების ჩანაცვლებით.
3. Vercel-ში გაუშვით ახალი Deployment.
4. ადმინპანელში გახსენით პროდუქტი, ატვირთეთ 2–3 ფოტო, შეინახეთ და გადაამოწმეთ პროდუქტის გვერდზე.
5. Checkout-ზე შეამოწმეთ „ფილიალში გადახდა“ — თბილისის და რეგიონის მიწოდება უნდა იყოს გათიშული. ბარათით/ინვოისით გადახდისას მიწოდება ისევ ხელმისაწვდომი უნდა იყოს.

**შენიშვნა:** სინტაქსი და არსებული FINA-ის ავტომატური ტესტები შემოწმებულია, მაგრამ რეალურ Firebase/Vercel გარემოში ინტეგრაციის ტესტი ჯერ არ ჩატარებულა. ცოცხალი საიტი ამ ZIP-ის შექმნით ავტომატურად არ განახლებულა.
