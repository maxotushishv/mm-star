- მარაგის შიდა ლოგიკა და კალათაში ხელმისაწვდომობის კონტროლი დარჩა.
- ზედა ნაწილში დაემატა „🔥 სააქციო პროდუქტები“ ღილაკი და ცალკე განყოფილება.
- „ყველა აქციის ნახვა“ აჩვენებს მხოლოდ saleActive პროდუქტებს, რომელთა effectivePrice საწყის ფასზე დაბალია.
- ადმინპანელი და FINA-ს საწყობის პარამეტრები უცვლელია.

## mmstar.ge არ იხსნება, www.mmstar.ge იხსნება
1. Vercel → Project → Settings → Domains: დაამატე **ორივე** `mmstar.ge` და `www.mmstar.ge`.
2. მთავარ დომენად აირჩიე `www.mmstar.ge` და მეორე მისამართისთვის დააყენე redirect, თუ www გინდა დარჩეს მთავარ მისამართად.
3. დომენის DNS-ის მართვის პანელში `@` (root/apex) ჩანაწერი ზუსტად Vercel-ის მიერ Domains-ში ნაჩვენებ რეკომენდაციაზე მიუთითე. თუ root-ზე Netlify-ის ძველი A/AAAA/ALIAS ჩანაწერია, გაასწორე ან წაშალე კონფლიქტური ჩანაწერი. www-ის მუშა CNAME არ წაშალო.
4. შეამოწმე Domains-ის ორივე ჩანაწერზე „Valid Configuration“ და SSL.
5. თუ მთავარ დომენად www რჩება, Keepz callback/return და PUBLIC_SITE_URL ერთიანად `https://www.mmstar.ge`-ზე უნდა გადაიყვანო; წინააღმდეგ შემთხვევაში Keepz-ს შეიძლება redirect/callback-ის პრობლემა ჰქონდეს. Keepz-ის ზუსტი მისამართები გადაამოწმე მის მართვის პანელში და არსებულ API კოდში.

DNS ჩანაწერის IP წინასწარ არ არის ჩაწერილი: გამოიყენე Vercel-ის კონკრეტული ინსტრუქცია Domains გვერდზე.

## დაყენება
ZIP-ის ფაილები განათავსე GitHub-ზე და გაუშვი Vercel deploy. ძველი გარემოს ცვლადები შეინარჩუნე. ეს ZIP ცოცხალ საიტს ავტომატურად არ ცვლის.
