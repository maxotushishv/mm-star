# MM STAR — ფოტოები და პროდუქტების ფილტრები

## 1. ფოტოები: `VERCEL_BLOB_NOT_CONFIGURED`
ეს შეცდომა ნიშნავს, რომ პროექტისთვის Vercel Blob-ის საცავი ჯერ არ არის მიერთებული.

1. Vercel Dashboard → აირჩიე MM STAR პროექტი → Storage.
2. Create Database / Add Storage → Blob → Create (მენიუს დასახელება შეიძლება განსხვავდებოდეს).
3. შექმნილი Blob Store მიაბი იმავე Vercel პროექტს და Production გარემოს.
4. შეამოწმე Environment Variables-ში `BLOB_READ_WRITE_TOKEN` — Vercel-მა ავტომატურად უნდა დაამატოს.
5. Deployments → Redeploy.
6. გახსენი Admin → Products → Edit/Add → აირჩიე ფოტოები → Upload → Save.

`BLOB_READ_WRITE_TOKEN` არ ჩაწერო HTML-ში, GitHub-ში ან ჩატში.
ამ განახლებაში ახლად ატვირთული ფოტოების ბმულები პირდაპირ Vercel Blob-ის საჯარო URL-ებია.
ძველი `/api/media/...` ბმულებისთვის დარჩა თავსებადობის მექანიზმი.

ფოტო მაქსიმუმ 3 MB; ერთ პროდუქტზე მაქსიმუმ 12 ფოტო.

## 2. ადმინპანელის ფილტრები
Admin → Products-ის თავში ახლა ჩანს:
- ძებნა კოდით, დასახელებით ან აღწერით;
- კატეგორიის და ქვეკატეგორიის ფილტრი;
- სააქციო / არააქციური ფილტრი;
- მარაგშია / 1–5 / ამოწურულია;
- ფილტრების გასუფთავება და 25 პროდუქტის გვერდებად დათვალიერება.

## 3. დაყენება
განახლებული ZIP ატვირთე GitHub-ის პროექტის ფაილებზე (დაიცავი Environment Variables);
Vercel-ში გაუშვი Redeploy და შეამოწმე როგორც კომპიუტერიდან, ისე ტელეფონიდან.
საიტი ცოცხალ გარემოში ამ ZIP-ით ავტომატურად არ განახლებულა.

FINA კვლავ ILHAMA №9 საწყობზეა; მეორე საწყობი არ დამატებულა.
