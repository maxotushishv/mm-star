MM STAR + FINA — Netlify AWS Lambda 4KB environment fix

This ZIP keeps storefront, Firebase, Keepz, UBILL and manual FINA integration.
The FINA scheduled function remains disabled, so automatic 10-minute sync is NOT active.

WHAT CHANGED:
- API accepts FIREBASE_PRIVATE_KEY_GZ, KEEPZ_PRIVATE_KEY_GZ, KEEPZ_PUBLIC_KEY_GZ
- Values are gzip-compressed, base64-encoded original PEM keys.
- API decompresses them in memory. Old uncompressed names are still supported
  for backward compatibility, but must be REMOVED from Netlify once new values are set.
- Never paste real keys into GitHub, public website, or this chat.

HOW TO CONFIGURE:
1. On your OWN computer open the separate offline helper file
   MM-STAR-KEY-COMPRESSOR-OFFLINE.html in Chrome or Edge (no internet required).
2. Paste each existing key's value from Netlify, generate compressed values.
3. In Netlify Environment variables add:
   FIREBASE_PRIVATE_KEY_GZ = compressed Firebase private key
   KEEPZ_PRIVATE_KEY_GZ = compressed Keepz private key
   KEEPZ_PUBLIC_KEY_GZ = compressed Keepz public key
   Scope: Functions (and Builds only if your build actually needs them).
4. DELETE old FIREBASE_PRIVATE_KEY, KEEPZ_PRIVATE_KEY, KEEPZ_PUBLIC_KEY
   from Netlify Environment variables AFTER confirming the new values were saved.
   Otherwise both sets are sent to Lambda and the 4KB error remains.
5. Keep FIREBASE_PROJECT_ID, FIREBASE_CLIENT_EMAIL, ADMIN_*, KEEPZ IDs,
   UBILL_*, PUBLIC_SITE_URL and existing payment settings untouched.
6. Keep FINA_ENABLED=false until the deploy works and a secure HTTPS connection
   to FINA API is configured. Do not send FINA credentials to an HTTP endpoint.
7. Redeploy the full project with this ZIP as source (not drag-drop static deploy).

IMPORTANT: Netlify deployment and real payment/FINA integrations are NOT tested
here; this change targets only the environment size issue. If your full environment
still exceeds 4KB after compression, the Netlify function will still fail. Inspect
new error logs; do not remove keys needed by runtime.
